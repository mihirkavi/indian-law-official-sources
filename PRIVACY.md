# Data handling

The package has no developer-operated backend, analytics or telemetry. The public downloader contacts the exact requested official HTTPS service and approved redirects. First-run `uv` dependency resolution contacts the configured Python package index. Government services and package indexes can log requests under their own policies.

The AI host is separate software. Prompts, tool calls and excerpts may be processed by that host/model provider; this package does not make them local-only. Search/browser connectors, authenticated sessions and schedulers have their own data handling. Review those policies before using confidential client facts.

Original bytes, extraction and metadata are stored in the explicit evidence directory selected by the user/host. Monitoring snapshots and watchlists remain in the authorized matter workspace. No shared legal-document cache, login credentials or session-cookie store is bundled. Saved hashes check consistency, not authenticity against an active writer.

Users enter required passwords/OTP only through an official service's private sign-in flow. Public access, CAPTCHA, fees and restricted API entitlement are separate. No private sign-in, CAPTCHA bypass, institutional API access or scheduled monitoring is created merely by installing the plugin.

Do not attach client records, evidence directories, credentials or raw AI-session transcripts to public GitHub issues. The repository publishes code, source-routing metadata, public-topic evaluation summaries and a curated demo; local raw sessions and downloaded records are excluded.
